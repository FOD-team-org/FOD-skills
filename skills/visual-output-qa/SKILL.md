# 시각 결과물 검수

우선순위: 실행 환경의 시스템 프롬프트·설정 > 사람의 지시 > 이 스킬. 부딪혀 결과가 달라졌으면 보고에 적는다.

## 순서
1. 판정에 쓸 프레임을 이미지 파일로 뽑고, 판정하는 쪽이 그 파일을 직접 연다(보고 문장으로 갈음하지 않는 규칙은 `delegation-loop`).
2. 한 장 추출: `ffmpeg -ss <초> -i src.mp4 -frames:v 1 f.png`
3. 좌표 실측: `ffmpeg -ss <초> -i src.mp4 -frames:v 1 -vf "drawgrid=w=100:h=100:t=2:c=red" grid.png` 격자 위에서 로고·자막바·레이블·번호 띠의 경계를 읽는다.
4. 0.5초 시트: `ffmpeg -ss <시작> -t <길이> -i src.mp4 -vf "fps=2,scale=320:-1,tile=6x4" -frames:v 1 sheet.png` 로 줌 시점, 결말 시작, 레이블 등장 구간을 찾는다.
5. 컷 경계 타일: 경계 프레임 P마다 `ffmpeg -i out.mp4 -vf "select='between(n,P-10,P+10)',scale=216:-1,tile=7x3" -fps_mode passthrough -frames:v 1 tile_P.png` 로 앞뒤 10프레임을 한 장에 본다.
6. 띠 스캔: 크롭 뒤 남을 수 있는 요소는 `python references/band_scan.py out.mp4 --box x0:y0:x1:y1 --expr "<조건>"` 로 쓰는 구간 전 프레임을 센다.
7. 스캔 조건은 요소가 있는 원본 프레임(양성)에서 걸리고 깨끗한 프레임(음성)에서 안 걸리는 것을 먼저 확인한 뒤 결과물에 돌린다.
8. 3프레임 이하로 걸린 구간은 그 프레임을 직접 열어 보고, 길게 걸린 구간은 시트로 조명·간판인지 가린다.
9. 고친 뒤 같은 타일·스캔 명령을 다시 돌려 `hits=0`과 타일 이미지를 함께 남긴다.

## 크롭 점검
| 항목 | 기준 |
|---|---|
| 크롭 박스 | 원본 프레임 격자에서 실측한 값만 쓰고, 파트마다 따로 정한다 |
| 행위자·물체 | 행위자와 물체를 먼저 프레임 안에 넣고, 메뉴·로고는 그 뒤에 경계를 실측해 피한다 |
| 가로 화면 속 세로 영상 | 세로 영상이 화면 폭의 2/3 미만이면 세로 코어만 잘라 쓴다 |
| 방송 레이블 | 일부 구간에만 뜨므로 쓰는 구간 전 프레임을 스캔한다 |
| 색 자막바 | 어둡고 채도 높은 띠(보라·남색)는 밝기 조건에 안 걸리니 색 조건을 같이 쓴다 |
| 흰 중심 반짝이 | 색 조건에 안 걸리니 밝기 조건(`L>170`)을 같이 쓴다 |
| 인용 카드 | 카드마다 글자 bbox를 따로 실측하고, 한 카드의 값을 재사용하지 않는다 |
| 문서 컷 | 시트로 줌 시점을 찾아 그 구간 안만 쓰고, 펀치인 네 변은 글줄 사이 빈 줄에 둔다 |
| 전화번호·간판 | 원본 크기로 보고 번호가 읽히면 움직임을 따라가는 국소 블러를 넣는다 |
| 재방송·다른 소스 | 같은 장면의 다른 소스에 더 깨끗한 프레임이 있는지 확인한다 |
| 비난 문장 위 B롤 | 사람이 나오는 B롤은 뒷모습이라도 쓰지 않는다 |
| 세로 쇼츠 UI | 플랫폼 버튼·설명이 덮는 하단·우측 띠에 핵심 글자를 두지 않는다 |
| 썸네일 큰 글자 | 2배로 확대한 캡처에서 획 깨짐·잘림을 본다 |

## 생성물 점검
| 항목 | 기준 |
|---|---|
| 결함 목록 | 손·손가락, 글자 깨짐, 얼굴 일부 잘림, 시안과 다른 구도를 장마다 표시한다 |
| 기각 전 대조 | 스펙에 적힌 조건과 대조하고, 스펙에 없는 이유로 기각하지 않는다 |
| 재생성 | 승인 없이 2회까지, 매번 새 시드 범위로 돌린다 |
| 얼굴 일부 | 같은 인물인지 애매하면 "동일성 판정 필요"로 사람에게 올린다 |
| 장부 | 파일·시드·채택 여부·사유를 한 줄씩 남긴다 |

## 시안 충실도
| 항목 | 기준 |
|---|---|
| 화면별 차이표 | 시안과 구현 캡처를 화면마다 나란히 두고 차이를 행으로 적는다 |
| 대비 | 확대 캡처에서 글자·배경 색을 뽑아 대비비 4.5:1 이상인지 계산한다 |
| 넘침 | 작은 폰·큰 폰·태블릿 폭 캡처에서 글자 잘림과 줄넘침을 본다 |
| 테마 상수 | 정의뿐 아니라 호출 지점에 적용됐는지 grep으로 확인하고, 옛 색 값은 grep 0건 |
| 에셋 크기 | 이미지 파일마다 미리 정한 용량 상한 이하 |
| 문구 | 화면 DOM 텍스트를 뽑아 확정 문안과 diff 한다 |

## 하지 않는 것
- 첫 프레임 하나만 보고 구간 전체를 통과시키지 않는다.
- 눈대중 좌표로 크롭하지 않는다.
- 메뉴·로고를 피하려고 행위자를 잘라내지 않는다.
