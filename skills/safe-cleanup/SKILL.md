# 안전한 정리

## 언제
- 디스크가 부족해 정리를 요청받았을 때
- 산출물 업로드 준비나 마감 뒤 프로젝트 폴더를 정리할 때
- 큰 폴더를 다른 드라이브로 옮길 때
- 필요 없는 프로세스를 정리해 달라는 요청을 받았을 때
- 정기 정리 작업을 만들 때

## 디스크 정리 순서
1. 읽기 전용으로 큰 항목을 잰다(폴더별 크기, 마지막 수정).
2. 등급표를 만든다.

| 등급 | 예 | 처리 |
|---|---|---|
| 1 다시 만들 수 있음 | 패키지 캐시, 오래된 임시 파일, 빌드 산출물 | 승인 후 일괄 |
| 2 내용 확인 필요 | 프로젝트 중간 산출물, 모델 캐시, 녹화본 | 항목별 승인 |
| 3 보고만 | 개인 파일, 에이전트 설정 폴더, 실행 중 세션의 임시 폴더 | 삭제 제안 안 함 |

3. 항목마다 무엇인지, 지워도 되는지, 다시 만들 수 있는지(다시 받는 데 드는 것)를 적는다.
4. 내용이 불분명한 항목은 제안에서 뺀다. 넣으려면 내용을 먼저 확인해 설명한다. 사람이 한 번 뺀 항목은 다음 제안에서도 뺀다.
5. 사람이 고른 항목만 지운다. 지운 목록을 매니페스트 파일로 남긴다.
6. 전후 여유 공간을 재서 보고한다.
- 시스템 설정 변경(최대 절전 파일 해제 등)은 관리자 승인을 받고, 되돌리는 명령을 함께 알린다.
- 용량은 OS에 맞는 방법으로 잰다. macOS(APFS)는 `du` 합이 아니라 `df`로 본다(macos-env-pitfalls).
- 앱이 관리하는 데이터는 앱의 공식 삭제 기능·API로 지운다. 내부 DB 파일을 직접 지우지 않는다.
- 되돌릴 수 없는 삭제는 등급표에 "되돌릴 수 없음"으로 표시한다. 클라우드로 먼저 백업했으면 원본과 백업의 sha256 대조 결과를 붙인다.

## 프로젝트 산출물 정리
- 보존: 완성본, 메타·로그·설정(json·md·txt·csv·자막), 게시 중복 확인에 쓰는 파일, 사람이 쓰는 결과 폴더
- 정리 대상: 일정 기간이 지난 작업 폴더의 중간 산출물(원본 소스 사본, QC 프레임, 렌더 조각, 반려본)
- 최근 수정된 작업 폴더는 건너뛴다. 기준 기간은 프로젝트에 맞게 정해 운영 문서에 적는다.
- 마감 정리: 최종본만 final 폴더에 두고 나머지는 _archive로 옮긴다. 삭제는 목록을 보여 주고 승인 뒤에만.
- 운영 문서에 "정리된 옛 작업을 다시 빌드하려면 원본을 다시 받아야 한다"를 적는다.

## 정기 정리 작업
- 위 보존·정리 기준을 작업 본문에 그대로 넣는다.
- 가드: 최근 며칠 안에 만든 매니페스트가 있으면 건너뛴다(수동 정리와 겹침 방지). 정리할 양이 작으면 건너뛴다.
- 실행 전후로 보존 대상 수(완성본 수, 메타 파일 수, 최근 폴더 수)를 세어 변화가 0인지 확인한다.

## 폴더 이동 (경로 유지)
1. 원본을 잡고 있는 프로세스·예약 작업이 없는지 본다.
2. 복사한다(robocopy 등). 요약 줄은 로케일에 따라 한글·영문으로 나오므로 둘 다 파싱하거나 종료 코드로 판정한다. 해석이 안 되면 멈춘다.
3. 파일 수·크기를 대조하고 표본 해시를 비교한다. 키 파일은 열지 않고 크기·수정 시각만 비교한다.
4. 원본을 치운 뒤 옛 경로에 정션(또는 심볼릭 링크)을 만든다.
5. 경로 의존을 갱신한다: 스케줄러 작업의 시작 폴더·인자, 에이전트 메모리·설정에 적힌 경로.
6. 옛 경로와 새 경로가 둘 다 열리는지 확인한 뒤, 승인을 받아 원본 사본을 지운다.
- 지금 세션이 작업 중인 폴더 자체를 옮길 때는 두 단계로 나눈다. 복사·검증까지 하고, 세션을 닫은 뒤 사람이 마무리 스크립트를 실행한다.

## 프로세스 정리
1. 지목된 프로세스가 실제로 있는지 먼저 본다.
2. 끄기 전에 전체 명령줄·부모 프로세스·시작 시각을 확인한다. 자기 백업·감시 프로세스, 다른 세션의 도구 서버, 사람의 브라우저를 구분한다.
3. 사실(무엇이 얼마나 쓰는지)과 끌 후보만 보고한다. 사람이 고른 것만 끈다.
4. 배치를 멈출 때는 실행기, 서버 순으로 끄고, 자식 프로세스와 점유 포트가 비었는지 확인한다.
5. 자기가 만든 프로세스는 작업 끝에 정리한다.

## 확인
- [ ] 지운 것이 승인 목록과 같다(매니페스트 대조)
- [ ] 보존 대상 수가 줄지 않았다
- [ ] 전후 용량을 쟀다
- [ ] 이동이면 옛 경로·새 경로 모두 동작한다

## 하지 않는 것
- 보고 없는 삭제, 하위 에이전트에게 영구 삭제 맡기기(임시 파일은 정해진 _tmp 폴더에만)
- 불분명한 캐시를 짐작으로 지우기
- 정체를 모르는 프로세스 종료
