# 영상·이미지 개인정보 가림

코드·응답·로그의 데이터 노출은 data-exposure-guard, 외부 자산 권리는 asset-rights-check를 따른다.

## 언제
- 실제 계정으로 찍은 화면을 영상·이미지로 공개할 때
- 시연용 데이터를 고를 때
- 공개 페이지에 운영자 정보를 넣을 때

## 가릴 대상
- 사람과 관련된 모든 값: 이름, 아이디·이메일, 프로필 사진, 전화번호, 주소, 저장물·대화 제목, 알림 미리보기
- 화면 구석의 상태 표시줄, 브라우저 탭 제목, 자동 완성 목록도 본다.

## 가리는 방법
- 단색 박스로 덮는다. 블러·모자이크는 쓰지 않는다. 복원될 수 있다.
- 움직이는 화면은 가림 위치가 프레임마다 맞는지 본다. 스크롤·전환 구간을 따로 확인한다.
- 가린 뒤 결과물을 직접 본다. 시작·끝·전환 프레임을 뽑아 확대해 확인한다(visual-output-qa).

## 시연 데이터
- 사람의 실제 데이터는 허락받은 범위(본인 계정 등)까지만 쓴다.
- 가능하면 시연용 계정과 지어낸 데이터를 쓴다. 지어낸 데이터는 실제 사람·회사와 겹치지 않게 한다.
- 스톡 영상은 이용이 허락된 곳에서만 받고, 직접 찍은 것처럼 내세우지 않는다.

## 운영자 정보
- 공개 페이지(사업자 표기, 문의처)에 넣는 운영자 개인정보는 법·스토어가 요구하는 최소한만 넣는다. 무엇을 넣을지는 사람이 정한다.

## 확인
- [ ] 모든 프레임에서 사람 관련 값이 단색 박스로 덮였다
- [ ] 블러를 쓴 곳이 없다
- [ ] 공개할 운영자 정보를 사람이 정했다
