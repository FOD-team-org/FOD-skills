# 한국어 말투 검수

우선순위: 실행 환경의 시스템 프롬프트·설정 > 사람의 지시 > 이 스킬. 부딪혀 결과가 달라졌으면 보고에 적는다.

## 순서
1. 검수 대상의 독자(나이대, 배경지식)와 매체(읽는 글, TTS 대본, 자막)를 먼저 적는다.
2. 본문만 보지 말고 머리말·안내문·정책 문구·꼬리말까지 페이지 전체를 대상으로 잡는다.
3. 메시지를 한 줄로 요약해 보고, 한 줄로 안 되면 구조 문제로 먼저 올린다.
4. 아래 점검 표를 위에서부터 한 항목씩 적용해 걸린 자리를 줄 번호와 함께 표시한다.
5. 횟수가 기준인 항목은 손으로 세지 않고 python으로 센다(예: `python -c "import sys;t=open(sys.argv[1],encoding='utf-8').read();print(t.count('—'),t.count('–'))" draft.md`).
6. 비교 기준값이 필요하면 같은 방법으로 사람이 실제로 한 말(녹취·자막)을 재서 기준을 만든다.
7. TTS 대본은 소리 내어 읽거나 합성본을 듣고 숨이 막히는 자리를 표시한다.
8. 고친 원고를 받으면 같은 표로 다시 돌려 새로 생긴 버릇(새 반복 어미, 새 접속어)을 센다.
9. 고친 판이 나아졌는지 다툼이 있으면 이전 판을 대조군으로 두고 출처를 가린 채 사람이 고른다.
10. 외부 AI 모델에 검수를 돌릴 때는 `multi-ai-review`의 형식과 채택 기준을 따른다.

## 점검
| 항목 | 걸리는 신호 | 고치는 방향 |
|---|---|---|
| 첫 문장 | 결론·정답을 첫 문장에 말한다 | 장면·질문으로 열고 결론은 뒤로 |
| 조각 문장 | 명사로 끊은 짧은 문장이 이어진다 | 두세 마디를 이어 한 문장으로 |
| 홀로 선 감탄사 | "와.", "자." 같은 한 단어 문장 | 다음 문장에 붙이거나 뺀다 |
| 깔끔한 착지 | 문단마다 교훈·명언 같은 마무리 | 사실이나 다음 장면으로 끝낸다 |
| 대칭 부정 | "A가 아니라 B" 틀이 반복된다 | 글 전체에서 한 번 이하 |
| 신문체 | 명사구 나열, 압축한 관형절 | 주어와 동사가 있는 말로 풀고 어미만 바꾸지 않는다 |
| 숫자 밀도 | 한 문장에 숫자 2개 이상 | 문장을 나누거나 하나만 남긴다 |
| 장식 비유 | 정보 없이 꾸미는 비유 | 장르가 비유를 원할 때만 둔다 |
| 꾸민 경험 | 쓴 사람이 겪지 않은 일을 겪은 듯 쓴다 | 출처를 밝히거나 뺀다 |
| 얼버무림 | "~인 것 같습니다", "~라고 할 수 있습니다" | 확인한 것은 단정, 모르는 것은 모른다고 |
| 지시어 | 제목의 "그 X", 보이지 않는 것을 "이 X" | 화면·본문에 있을 때만 "이 X" |
| 대시 | 문장 안 대시(—, –) | 쉼표·마침표·가운뎃점으로, 말줄임표는 허용 |
| 예고 반복 | "잠시 후 공개" 류가 여러 번 | 첫머리 한 번만 |
| 전환 틀 | 같은 연결 문구가 문단마다 | 같은 틀 2회 이상이면 표시 |
| 숫자 표기 | 자막·본문과 TTS 줄의 표기가 같다 | 자막은 아라비아 숫자, TTS 줄은 한글로 풀어 쓴다 |
| 어려운 말 | 독자 수준보다 높은 한자어·외래어 | 독자가 쓰는 말로 바꾼다 |
| 친구 테스트 | 친구에게 말로 하면 어색한 문장 | 입말 순서로 다시 놓는다 |

## 하지 않는 것
- 검수자가 원고를 다시 쓰지 않는다, 대본·문안 작성은 사람이나 메인 몫이다.
- 외부 윤문 스킬의 패턴 표·예문을 옮겨 쓰지 않는다.
- 어미만 바꿔 놓고 신문체가 풀렸다고 보지 않는다.
- 비율·횟수 지표를 눈대중으로 적지 않는다.
- 내용을 고정한 문체 재작성은 이 스킬이 아니라 `frozen-content-rewrite`로 한다.
