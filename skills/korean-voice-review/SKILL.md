# 한국어 말투 검수

이 스킬은 검수만 한다. 글을 쓰고 고칠지 정하는 것은 작성자(사람 또는 메인 에이전트)다.

## 언제
- 공개할 글, 영상·음성 대본, 자막과 화면 문구, 설명란을 마무리할 때
- "AI가 쓴 것 같다", "딱딱하다", "어렵다"는 지적을 받았을 때

## 순서
1. 범위는 글 전체다. 첫 문단만 보지 않는다. 페이지라면 소개·안내·바닥글까지 본다.
2. 소리 내어 읽는다. 대본은 실제 음성 합성 샘플로 들어 본다.
3. 아래 목록으로 표시한다. 표시마다 위치(문단·줄), 문제, 고칠 방향을 적는다. 고친 문장은 선택지로만 낸다.
4. 문장 길이·연결어 빈도·같은 어미 반복 같은 수치는 코드로 센다. 손으로 세지 않는다.
5. 수정본이 오면 같은 목록으로 다시 보고, 새로 생긴 말버릇이 없는지 본다.
6. 수정 뒤 사실 항목이 바뀌지 않았는지는 fact-check-gate로 넘긴다.

## AI 티 점검
| 항목 | 보이는 모습 |
|---|---|
| 깔끔한 착지 | 모든 문장이 완결되고 매끈하게 끝난다 |
| 대칭 구조 | "A가 아니라 B" 같은 균형 문장이 반복된다 |
| 격언 마무리 | 교훈이나 명언처럼 끝나는 문장 |
| 글말 어휘 | "해석한다", "다루고 있다", "~라는 점입니다" |
| 조사 과다 | 말할 때는 빼는 조사까지 다 붙어 있다 |
| 보도체 구조 | 명사구로 압축한 문장, 긴 관형절. 어미만 구어로 바꿔도 구조가 보도체면 AI로 들린다 |
| 번역투 | 외국어 문장을 그대로 옮긴 듯한 어순과 표현 |
| 기계적 병렬 | 같은 길이·같은 틀의 문장이 줄지어 나온다. 넘김 말을 한 틀로 되풀이한다 |
| 접속사 과다 | 문장마다 "또한", "그리고", "하지만"으로 시작한다 |
| 꾸밈 비유 | 비유·은유가 잦다. 한국어 독자는 이것으로 AI 글을 바로 알아챈다 |
| 대시 | 문장 안 대시는 쉼표·마침표·가운뎃점으로 바꾼다. 말이 끊기는 연출만 말줄임표를 쓴다 |
| 새 말버릇 | 문단 끝마다 같은 어미가 반복된다 |

## 말 흐름 (특히 음성 합성 대본)
- 짧은 조각 문장이 이어지면 음성 합성이 조각마다 같은 억양으로 읽어 기계처럼 들린다. 절 두세 개를 연결 어미로 이어 한 호흡으로 만든다.
- 감탄사만 따로 한 문장으로 두지 않는다. 뒤에 이어지는 말과 붙인다.
- 감정은 음성 설정이 아니라 문장 안에 넣는다.
- 한 문장에 숫자를 두 개 이상 넣지 않는다.
- 자막 줄은 아라비아 숫자, 낭독 줄은 한글로 풀어 쓴 숫자를 따로 둔다.
- 기준: 이 문장을 친구에게 말로 하겠는가.

## 영상 대본의 이탈 위험
- 첫 문장에 결론이나 판정을 말하지 않는다. 답을 먼저 말하면 그 자리에서 이탈한다.
- 예고는 도입에서 한 번만 한다. "뒤에서 다시", "기억해 주세요", "아까 말한" 같은 예고·되돌림을 반복하지 않는다.
- 처음 보는 사람이 모르는 공유 맥락을 전제하는 지시어("그 사건", "그 사람")를 첫머리에 쓰지 않는다. 화면에 보이는 대상은 "이"로 가리키거나 명사를 쓴다.
- 무엇을 전하려는지 한 문장으로 말할 수 있는지 본다. 못 하면 작성자에게 되묻는다.

## 쉬운 말
- 독자를 먼저 정한다(예: 중학생, 처음 접하는 고령 독자). 그 독자가 모를 용어는 풀어 쓰거나 뺀다.
- 설명은 짧게 쓴다. 길고 정중한 설명문은 AI 티로 읽힌다.

## 확인
- 표시 목록이 글 전체 위치를 덮는다(마지막 문단·바닥글 포함).
- 수치 점검 값이 코드 출력이다.
- 수정본에서 새 말버릇 0건.

## 하지 않는 것
- 검수자가 글을 다시 써서 바꿔 넣지 않는다.
- 지어낸 경험("저도 가 봤는데")을 제안하지 않는다.
- 비속어·유행어로 구어 느낌을 내자고 제안하지 않는다.
- 다른 모델의 윤문 결과를 그대로 채택하지 않는다(multi-ai-review의 채택 필터를 거친다).
