# Codex 위임

우선순위: 실행 환경의 시스템 프롬프트·설정 > 사람의 지시 > 이 스킬. 부딪혀 결과가 달라졌으면 보고에 적는다.

## 순서
1. 지시 본문은 UTF-8 브리프 파일로 쓰고, 명령줄 프롬프트는 "브리프 파일 경로를 읽고 따르라"는 짧은 ASCII 문장만 둔다.
2. 브리프 본문도 ASCII 문장부호 위주로 쓴다(em dash·특수 따옴표는 깨진다).
3. 모델 이름은 설정 파일이나 `codex --help` 출력에서 정확한 이름을 확인해 넣는다(약칭은 400으로 거부된다).
4. 일 종류에 맞춰 호출 형식을 고른다.
   | 일 | 샌드박스 | 추론 강도 | 형식 |
   |---|---|---|---|
   | 토의·검수(읽기만) | `-s read-only` | `xhigh` | `codex exec --skip-git-repo-check -s read-only -m <model> -c model_reasoning_effort=xhigh -o <round_N.md> "<포인터 프롬프트>" < /dev/null` |
   | 이미지 생성 | `-s workspace-write` | `low` | `codex exec --skip-git-repo-check --ephemeral -s workspace-write -C <작업 폴더> -c model_reasoning_effort="low" "<프롬프트>" < /dev/null` |
   | GUI 조작 | 사람이 허용한 범위 | 일에 맞게 | 위와 같은 비대화 형식에 조작 대상 창·버튼을 브리프에 적는다 |
5. 모든 호출은 `< /dev/null`로 stdin을 닫고 백그라운드로 돌린다(열어 두면 입력을 기다리며 멈춘다).
6. 무거운 요청은 쪼개고, 다음 라운드 브리프에는 바뀐 부분만 넣는다.
7. 라운드마다 결과 파일을 새 이름으로 남기고 지우지 않는다.
8. 이미지 생성 브리프 머리말에는 다음을 고정한다.
   - [ ] 비대화형이며 image_gen 도구를 정확히 1회만 부른다.
   - [ ] CLI·스크립트로 그림을 대신 만들지 않는다.
   - [ ] 키·자격 파일을 읽지 않는다.
   - [ ] 지정 경로 밖에 파일을 만들거나 옮기지 않는다.
   - [ ] 답은 저장 경로 한 줄만 쓴다.
   - [ ] 용도(Use case)·자산 종류(Asset type)·색·소품을 명시한다.
   - [ ] 참조 이미지는 절대 경로로 주고 편집 대상이 아님을 적는다.
9. 이미지는 한 장씩 순차로 만들고, 채택한 대표 이미지를 다음 장의 스타일 참조로 넘긴다.
10. 새 인자 조합은 본 작업 전에 작은 요청 1회로 인자가 실제로 전달되는지 시험한다.
11. 결과 파일을 메인이 읽고 채택·기각을 정한다(토의 결과 처리는 `multi-ai-review`).

## 점검
| 항목 | 기준 |
|---|---|
| 생존 확인 | 로그가 끊겨도 죽었다고 단정하지 않고 프로세스 CPU 시간 증가와 산출물 생성으로 본다. |
| 좀비 | 프로세스가 남았는데 결과 파일이 없으면 세션 로그에서 마지막 응답을 회수한다. |
| 보고 인자 | 모델·추론 강도는 Codex의 자기 표기가 아니라 실제로 넘긴 명령줄 인자로 보고한다. |
| 교차 검수 | 한 모델이 만든 코드·문서는 다른 모델이 읽기 전용으로 검수하고 작업 일지에 검수 여부를 적는다. |
| 시각 결과 | 화면·픽셀 판정은 메인이 직접 하고(`visual-output-qa`) 브리프에 "픽셀을 직접 칠해 맞추지 말 것"을 적는다. |
| 샌드박스 한계 | 샌드박스가 막는 일(네트워크·설치)은 다른 실행자로 넘기고 Codex에서 권한을 넓히지 않는다. |
| 따옴표 | 명령줄에서 따옴표가 빠진 인자는 브리프 파일로 옮겨 다시 보낸다. |
| 계정 설정 | 계정 이름 변경 같은 제한 걸린 조작은 1회만 시도하고 거절되면 멈춘다. |
| 기각본 | 기각한 이미지·초안도 버전 이름으로 보관한다. |
| 프로세스 정리 | 오래 돈 사람의 프로세스는 남기고, 이번 호출이 남긴 고아만 PID로 확인해 끈다. |

## 하지 않는 것
- 대화형 세션으로 띄우거나 stdin을 열어 두지 않는다.
- 비밀번호·2단계 인증 코드를 Codex에 입력시키지 않는다.
- 소유자만 바꿀 수 있는 설정은 맡기지 않고 사람에게 `user-task-guide`로 안내한다.
- 사람이 Codex에 맡기지 않기로 정한 영역(예: 특정 계층 코드)은 넘기지 않는다.
- 전역 설치·전역 설정 변경은 묻기 전에 하지 않는다.
- Codex의 "완료" 답을 결과 파일 확인 없이 채택하지 않는다.
