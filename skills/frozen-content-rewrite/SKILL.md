# 내용 고정 재작성

우선순위: 실행 환경의 시스템 프롬프트·설정 > 사람의 지시 > 이 스킬. 부딪혀 결과가 달라졌으면 보고에 적는다.

## 순서
1. 원본 폴더를 읽기 전용으로 두고, 재작성본은 새 폴더에 같은 파일 이름으로 쓴다.
2. 원본에서 고정 항목 목록을 뽑는다: 제목 순서, 표, 인용·박스, 숫자, 링크, 고유명사·전문 용어.
3. 고유명사·전문 용어는 한 줄에 하나씩 `terms.txt`로 저장한다.
4. 메인이 문체 지침(바꿀 것, 남길 것, 금지 표현)과 금본 한 편(원본 1절을 직접 재작성한 예)을 쓴다.
5. 길이 범위를 미리 정한다(예: 공백 뺀 글자 수 +10%~+30%, 상한 +35%).
6. 작성자마다 지침·금본·고정 항목 목록·길이 범위를 같은 문구로 넘기고 파일 단위로 나눠 병렬로 맡긴다.
7. 재작성본마다 검사기를 돌린다: `python references/check_frozen.py 원본.md 재작성.md --terms terms.txt --len-min 0.10 --len-max 0.35`
8. 검사기가 종료 코드 1을 내면 FAIL 줄을 그대로 작성자에게 돌려보내 그 자리만 고치게 한다.
9. 검사기를 통과한 판은 `korean-voice-review` 표로 말투를 보고, 여러 편에 같은 새 버릇이 보이면 정정 공지를 모든 작성자에게 한 번에 보낸다.
10. 정정 공지 뒤에는 이미 끝난 파일도 검사기와 말투 표를 다시 돌린다.
11. 모든 파일이 실패 0건이면 원본과 재작성본 쌍 목록, 길이 변화율, 실패 이력을 보고한다.

## 점검
| 항목 | 기준 |
|---|---|
| 제목 | `#` 줄의 글자와 순서가 원본과 같다 |
| 표·인용 | 표 줄(세로선으로 시작) 수와 `>` 줄 수가 원본과 같다 |
| 숫자 | 쉼표를 뺀 숫자 다중집합이 원본과 같다(추가도 실패) |
| 링크 | 링크 집합이 원본과 같다 |
| 용어 | `terms.txt` 각 용어의 등장 횟수가 원본 이상이다 |
| 길이 | 공백 뺀 글자 수 변화율이 미리 정한 범위 안이다 |
| 원본 보존 | 원본 폴더 파일의 수정 시각이 작업 전과 같다 |
| 약한 모델 | 지침 문구가 작은 모델에서도 같은 결과를 내도록 예시와 금지 목록으로 적혀 있다 |

## 검사기
- 위치: `references/check_frozen.py` (표준 라이브러리만 쓴다).
- 출력: 길이 변화율·숫자 수·링크 수·실패 수 한 줄, 그다음 실패마다 `FAIL` 한 줄.
- 기본 길이 범위는 -5%~+35%이고, 늘리는 재작성이면 `--len-min`을 올려 준다.
- 검사기가 못 보는 것(뜻이 바뀐 문장, 주어가 바뀐 인용)은 `fact-check-gate`의 대조로 따로 본다.

## 하지 않는 것
- 원본 파일을 덮어쓰지 않는다.
- 작성자가 설명을 늘리려고 숫자·예시·사례를 새로 넣지 않는다.
- 검사기 실패를 검사기 기준을 풀어서 통과시키지 않는다.
- 작성자마다 다른 지침을 주지 않는다, 지침이 바뀌면 모두에게 같은 공지로 보낸다.
