# 속도 지키는 조사

우선순위: 실행 환경의 시스템 프롬프트·설정 > 사람의 지시 > 이 스킬. 부딪혀 결과가 달라졌으면 보고에 적는다.

## 순서
1. 조사 브리프를 아래 칸으로 쓴다.
   - [ ] 저장소 목적과 사람이 건 조건
   - [ ] 먼저 읽을 것: README·후보 목록·판정 기준·측정 방법·이미 확인한 라이선스 문서(재조사 금지 표시)
   - [ ] 속도 규칙: 사이트당 동시 1개, 병렬·백그라운드·스레드 금지, 사이트별 요청 간격
   - [ ] 전체 상한: 검색·페이지·다운로드를 합친 요청 수
   - [ ] 결과 표 형식과 저장 위치
2. 대량 수치는 공식 API로 받고, 페이지 크롤링은 API가 없는 소량에만 쓴다.
3. 요청은 한 번에 하나씩 보내고 요청 사이에 정한 간격을 둔다.
4. `yt-dlp` 같은 수집 도구는 한 건씩 실행하고 여러 명령을 이어 붙이지 않는다.
5. 영상 다운로드는 시간당 10편 이하, 워커 1개, 요청 간격 10초 이상으로 둔다.
6. 자막은 원어 자막만 받고 자동 번역 자막은 요청하지 않는다(429를 부른다).
7. 모든 호출을 호출 로그 csv(시각·대상·결과 코드)에 남기고, 다음 작업 전에 그 로그로 상한 남은 양을 본다.
8. 받은 파일은 새 빈 untrusted 폴더에 두고, 읽는 `python`은 `-I`로 돌린다.
9. euc-kr 등 다른 인코딩 페이지는 UTF-8 파일로 바꿔 저장한 뒤 읽는다.
10. 출처는 페이지 문구를 직접 읽고 원문 인용·URL·조회 시각을 함께 적는다.
11. 수집한 링크·숫자는 별도 감사 단계에서 표본을 원문과 대조한다.
12. 보고에는 속도 규칙 위반이 있었으면 한 줄로 적는다.

## 점검
| 항목 | 기준 |
|---|---|
| 403·429 | 기다린 뒤 1회만 재시도하고, 다시 막히면 그 대상은 멈춘다. |
| 사이트 차단 | 한 사이트가 막히면 그 사이트만 멈추고, 주요 플랫폼이 막히거나 3곳이 막히면 전체를 멈춘다. |
| Access Denied | 거부 응답이 오면 우회하지 않고 멈춰서 보고한다. |
| 크롤 금지 문구 | 이용약관·robots에 수집 금지가 있는 사이트는 저장하지 않는다. |
| 파싱 오류 | 조회수 자릿수·단위(천·만)가 다른 표본과 크게 어긋나면 파싱 오류를 먼저 의심하고 원문을 연다. |
| 인용 대조 | 인용문은 원문 위치와 조회 시각으로 다시 대조한다. |
| 공공 자료 | 공공 포털 자료는 허용된 다운로드 범위 안에서만 받는다. |
| 사람 PC 영향 | 브라우저가 느려지거나 IP 차단이 보이면 즉시 멈추고 보고한다. |

## 하지 않는 것
- 로그인·쿠키·프록시로 차단이나 제한을 우회하지 않는다.
- 조사를 위해 계정을 만들거나 API 키를 발급받지 않는다.
- 방화벽·네트워크 설정을 바꾸지 않고 판단 필요로 올린다.
- 정한 상한을 넘겨 "조금만 더" 요청하지 않는다.
- 이미 확인한 라이선스·자료를 다시 조사하지 않는다.
