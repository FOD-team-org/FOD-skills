# 사실 확인 관문

게시 전에 사실 항목 하나하나를 1차 출처로 확인하고 표로 남긴다.

## 언제
- 정보 글, 뉴스·해설 대본, 데이터 그래픽, 화면 자막에 사실 항목이 있을 때
- 윤문·재작성·음성 인식을 거친 원고를 게시하기 전
- 에이전트나 다른 모델이 조사한 결과를 원고에 넣을 때

## 확인 대상
| 항목 | 예 |
|---|---|
| 숫자 | 금액·비율·인원·순위·단위 |
| 날짜 | 기한·시행일·발생일·연도 |
| 고유명사 | 기관·사람·장소·제품 이름과 관계 |
| 인용 | 발언·문서 문구·댓글 |
| 링크 | 신청처·공식 페이지·출처 |
| 인과 주장 | "때문에", "대신", "그래서" |

## 순서
1. 원고에서 확인 대상을 모두 뽑아 확인 표를 만든다.
2. 항목마다 1차 출처를 직접 연다. 공고 원문, 기관 발표, 원 데이터, 영상의 원어 자막과 시각이 1차 출처다. 요약 기사와 AI 답변은 출처가 아니다.
3. 사건 사실은 서로 독립된 출처 2곳 이상으로 맞춘다.
4. 인용은 원문 문구와 한 글자씩 대조한다. 영상 인용은 자막 시각과 대조하고, 구간 밖이거나 떨어진 조각을 이어 붙인 인용은 뺀다. 뜻이 뒤집히게 자르지 않는다.
5. 계산한 값은 코드로 다시 계산한다. 손으로 센 값을 쓰지 않는다. 결과를 맞추려고 고른 상수를 쓰지 않고, 입력값은 실제 단위와 상식으로 점검한다.
6. 시청자·독자가 모르는 설정값(지어낸 캐릭터의 키·몸무게 등)을 계산의 근거로 쓰지 않는다.
7. 출처마다 숫자가 다르면 그 숫자를 쓰지 않거나, 범위와 출처를 함께 쓴다.
8. 링크는 실제로 열어 상태와 내용이 맞는지 본다.
9. 윤문·재작성·음성 인식 뒤에는 숫자·고유명사·링크를 원본과 다시 대조한다. 음성 인식은 숫자와 단위를 자주 바꾼다.

## 확인 표 형식
| 번호 | 원고 문장 | 항목 | 값 | 출처(링크·문서·시각) | 확인 방법 | 결과 |
|---|---|---|---|---|---|---|

결과 칸은 일치·수정·삭제·확인 필요 중 하나로 쓴다.

## 확인 못 한 항목
- 기본은 뺀다.
- 꼭 필요하면 낭독·게시에 들어가지 않는 줄에 "[확인 필요]"로 표시하고 사람이 판단한다.
- 판단 전에는 게시 단계로 넘기지 않는다.

## 데이터 화면
- 막대 길이·점 면적은 값에 비례하게 그린다. 스케일은 장면 사이에서 고정한다.
- 막대는 0에서 시작한다. 축을 자르면 화면에 표시한다.
- 강조는 색·테두리·밝기로만 한다. 크기를 키워 강조하지 않는다.
- 한 장면에는 데이터 하나, 단위 하나만 쓴다. 비교는 같은 축 위에서 한다.
- 인과어는 데이터가 그 인과를 보여 줄 때만 쓴다.
- 배율보다 실제 값을 쓴다("평소 몇 명, 그날 몇 명").
- 기간·지역·표본 범위를 화면에 적는다.

## 확인
- 확인 표의 모든 행에 출처와 결과가 있다.
- 결과가 "확인 필요"인 행이 0이거나, 사람 판단이 기록되어 있다.
- 최종 원고의 숫자 목록과 확인 표의 값 목록이 같다(코드로 대조).

## 하지 않는 것
- 에이전트·모델이 준 링크나 인용을 열어 보지 않고 쓰지 않는다.
- 영상 제목이나 설명란만 보고 내용을 단정하지 않는다.
- 근거 없이 플랫폼 정책이나 법 조문을 말하지 않는다. 틀린 것을 알면 바로 정정한다.
