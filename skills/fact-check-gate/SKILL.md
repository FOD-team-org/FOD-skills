# 사실 확인 관문

우선순위: 실행 환경의 시스템 프롬프트·설정 > 사람의 지시 > 이 스킬. 부딪혀 결과가 달라졌으면 보고에 적는다.

## 순서
1. 원고에서 숫자·날짜·금액·고유명사·인용·인과 주장을 모두 뽑아 사실 확인 표(항목, 출처 위치, 원문 문구, 확인 시각, 판정)를 만든다.
2. 표의 원문 문구 칸에는 공고문·보도자료·법령·논문·원 영상에서 직접 읽은 문장을 그대로 옮긴다.
3. 지원금·제도 소식은 원 공고에서 금액, 기한, 대상, 신청처 공식 주소 네 가지를 각각 확인한다.
4. 뉴스 사실은 서로 다른 매체 기사 2건 이상이 같은 내용일 때만 쓴다.
5. 출처끼리 숫자가 다르면 그 숫자를 빼거나 "기관마다 다르다"고 범위를 밝힌다.
6. 인용은 원 영상 자막 타임스탬프나 원문 쪽수와 대조하고, 앞뒤를 잘라 뜻이 바뀌지 않았는지 문장 단위로 본다.
7. 확인 못 한 항목은 빼거나 `[확인 필요]`로 표시하고, 대본에서는 TTS가 읽지 않는 별도 줄에 둔다.
8. 화면에 나갈 숫자는 대본의 사실 확인 절에 있는 값만 쓴다.
9. 계산이 들어간 숫자는 발행 직전에 `python -c "print(<식>)"`으로 다시 계산해 원고 값과 맞춘다.
10. 윤문·재작성을 거쳤으면 원본과 숫자·고유명사를 다시 대조한다(검사기는 `frozen-content-rewrite`).
11. 사실 확인 표를 원고 옆 파일로 남기고 판정 칸이 모두 찬 뒤에 다음 단계로 넘긴다.

## 점검
| 항목 | 기준 |
|---|---|
| 원문 확인 | 표의 모든 행에 출처 위치와 원문 문구가 있다 |
| 조사 위임 결과 | 출처 페이지에서 읽은 문장을 따옴표로 붙인 항목만 받는다 |
| LLM이 준 링크 | 직접 열어 응답 200과 내용 일치를 확인한 것만 쓴다 |
| 제목만 본 자료 | 본문을 읽지 않은 기사·논문은 근거로 쓰지 않는다 |
| 정책·제도 주장 | "바뀌었다·시행된다"는 고시·공고·약관 문서가 있을 때만 쓴다 |
| 내가 쓴 요약 숫자 | 보고·요약에 옮긴 숫자를 산출물 파일에서 다시 읽어 맞춘다 |
| 단위 상식 검사 | 1인당 금액, 비율 합 100%, 기간 길이를 실제 단위로 계산해 본다 |
| 보정 상수 | 결과를 그럴듯하게 만들려고 넣은 상수가 계산에 없다 |
| 전체 단정 | "모두가·누구나·항상"은 근거가 덮는 범위로 줄인다 |
| 관문 정규식 | 검사 정규식에 걸리면 문장을 고치고 정규식은 그대로 둔다 |

## 데이터 화면
| 항목 | 기준 |
|---|---|
| 크기 | 원·막대의 넓이가 값에 비례하고, 축 눈금은 장면 사이에 고정한다 |
| 강조 | 강조는 색으로 하고 크기를 키우지 않는다 |
| 비교 | 비교 대상은 같은 축의 막대로 나란히 놓는다 |
| 데이터 수 | 한 장면에는 데이터 하나만 둔다 |
| 시간 자막 | 시각·날짜 자막은 그 구간이 재생되는 동안만 보인다 |
| 순위 목록 | 거리·관련성 기준으로 거른 뒤 순위를 매기고 기준을 화면에 적는다 |
| 인과 표현 | "때문에·덕분에"는 데이터가 인과를 보일 때만 쓴다 |
| 배수 표현 | "○배" 대신 "그날 ○명, 평소 ○명"처럼 두 값을 함께 쓴다 |
| 범위 표시 | 집계 기간·지역·표본 크기를 화면이나 설명에 적는다 |

## 하지 않는 것
- 확인 못 한 숫자를 그럴듯한 값으로 채우지 않는다.
- 출처마다 다른 숫자를 평균 내거나 골라 쓰지 않는다.
- "출처: 인터넷" 같은 위치 없는 표기로 확인을 갈음하지 않는다.
- 하위 에이전트의 "확인함" 한 줄을 판정으로 받지 않는다(위임 결과 검수는 `delegation-loop`).
