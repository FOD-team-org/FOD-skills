# macOS 작업 함정

이 목록은 프로젝트 지침과 위임 프롬프트에 붙여 쓴다.

## 언제
- macOS에서 스크립트·도구를 실행하거나 위임할 때
- 같은 명령이 Linux·Windows에서는 되는데 여기서만 실패할 때
- 예약 작업·자동 조작이 사람이 볼 때는 되고 무인일 때만 실패할 때
- 빌드·테스트가 코드와 무관해 보이는 오류로 멈출 때

## zsh
| 상황 | 함정 | 대처 |
|---|---|---|
| `echo ====` | `=`로 시작하는 단어를 명령 경로로 확장해 `= not found` | 구분선은 따옴표로 감싼다 |
| `?`·`*`가 든 URL·인자 | 맞는 파일이 없으면 명령 전체가 `no matches found`로 실패 | URL과 패턴은 따옴표로 감싼다 |
| 큰따옴표 안 프롬프트 | 백틱·`$()`가 실행된다 | 프롬프트는 `<<'EOF'` heredoc으로 파일에 쓰고 파일을 넘긴다 |
| `set -- $x`, `for a in $x` | bash와 달리 공백으로 나누지 않는다 | 배열을 쓰거나 `${=x}` |
| 셸 상태 | 호출마다 새 셸이면 함수·변수가 남지 않는다 | 필요한 값은 한 호출 안에서 정하거나 파일로 넘긴다 |

## 없는 도구, 다른 도구
| 도구 | 차이 | 대처 |
|---|---|---|
| 시스템 bash | 3.2라서 `declare -A`·`mapfile`이 없다 | 연관 배열이 필요하면 파이썬 |
| sed | BSD라서 `sed -i ''`, 여러 줄 치환이 다르다 | 여러 줄 치환은 파이썬 스크립트로, 치환 횟수 assert |
| ls·stat·date | 옵션이 GNU와 다르다(`ls -lT`, `stat -f`, `date -j`) | 시각·크기는 파이썬으로 읽는다 |
| timeout | 기본으로 없다 | `gtimeout`, 또는 백그라운드 실행 + 시간 뒤 kill |
| grep 대체 도구 | 일부는 전방 탐색 `(?!...)`를 지원하지 않는다 | 파이썬 `re` |
| python3 | `-I`는 사용자 site-packages를 건너뛴다 | 필요한 패키지는 venv에 두고 venv 파이썬으로 실행 |
- Homebrew 파이썬이 올라가면 그 위에 만든 venv가 깨진다. 오래 도는 작업의 venv는 버전을 고정하고, 깨지면 다시 만든다.
- 파이프 끝에 `| tail`을 붙이면 앞 명령의 실패 코드가 사라진다. `set -o pipefail`을 쓰거나 출력을 파일로 받고 종료 코드를 따로 본다.

## 경로와 파일
- `-`로 시작하는 파일 이름은 `./-name`이나 `--` 뒤에 둔다.
- 기본 파일 시스템은 대소문자를 구분하지 않는다. 경로 비교·중복 검사는 대소문자 무시로 한다. 대소문자만 다른 파일 둘은 공존할 수 없다.
- `/private/tmp`(`/tmp`)는 며칠 지나면 비워진다. 다시 쓸 스크립트와 기록은 저장소나 홈 아래에 둔다.
- 비ASCII 작업 폴더에서 실패하는 도구가 있다. ASCII 경로로 복사하거나 ASCII 이름의 심볼릭 링크를 만들어 거기서 실행한다.
- iCloud로 동기화되는 폴더(데스크톱·문서 포함 가능)의 파일은 내용이 로컬에 없는 상태일 수 있다. 무인 작업이 읽으면 `Errno 11` 같은 오류가 난다. 예약 작업이 쓰는 코드·데이터는 동기화 폴더 밖에 둔다.
- 동기화 폴더의 파일 이름에 줄바꿈 없는 공백(U+00A0)이 섞일 수 있다. 이름으로 찾지 못하면 바이트를 본다.

## 시각
- 저장은 UTC로 하고, 비교는 날짜·시각 객체로 한다. 지역 시각 문자열과 UTC 문자열을 문자열로 비교하면 시차만큼 어긋난다.
- 보고에 적는 시각은 `date` 출력으로 쓴다.

## 권한과 화면 상태
- TCC: 백그라운드 프로세스가 데스크톱·문서·다운로드 폴더에 처음 접근하면 허용 창이 뜨고, 무인 작업은 그 창에서 멈춘다. 자동 조작 도구도 이 창을 누르지 못한다. 데이터를 보호 폴더 밖으로 옮기거나, 권한을 받은 앱 래퍼로 실행한다(launchd-ops).
- 화면이 잠기면 화면 조작 자동화가 창을 찾지 못하고 실패한다. 화면 조작 작업은 시작 전에 잠금 상태를 확인하고, 잠겨 있으면 별도 종료 코드로 끝낸다. 도는 동안은 `caffeinate -d -i`로 잠들지 않게 한다.
- 에이전트 샌드박스 안에서 `open URL`은 실패할 수 있다(-10661). 사람에게 링크를 주거나 샌드박스 밖에서 연다.

## 샌드박스·빌드 실패
| 증상 | 판단 | 대처 |
|---|---|---|
| `EPERM`(포트 열기, 패키지 캐시 쓰기, 공유 메모리) | 환경 제약. 코드 결함이 아니다 | "실행 못 함"으로 보고하고 샌드박스 밖 실행 명령을 준다 |
| xcodebuild "is not a workspace file", CoreSimulator 오류 | 환경 문제 | 코드를 고치지 않는다. 시뮬레이터 서비스 상태부터 본다 |
| "iOS xx is not installed" | SDK·런타임 문제일 수 있다 | 새 기본 프로젝트로 같은 오류가 나는지 먼저 본다. 런타임 설치는 승인 후 |
| 시뮬레이터 첫 설치 실패(IXErrorDomain 2) | 일시 오류인 경우가 많다 | 한 번만 다시 시도한다 |
| xcodebuild가 출력 없이 멈춤 | 새는 파이프가 쌓여 파이프 버퍼가 줄었을 수 있다 | 오래 남은 자식 프로세스를 정리하고, 안 되면 재부팅을 제안한다 |
- 디버그 서명 키의 지문은 기기마다 다르다. 지문을 등록하는 서비스(로그인 SDK 등)는 기기마다 따로 등록한다.

## 디스크와 메모리
- 여유 공간은 `df -k /System/Volumes/Data`로 잰다. APFS에서 `du`를 합하면 공유·복제 블록 때문에 맞지 않는다.
- 설정 앱의 "시스템 데이터"는 분류 이름이지 폴더 크기가 아니다. 그 숫자를 근거로 시스템 폴더를 지우자고 하지 않는다.
- 스왑 파일, Preboot, 로컬 스냅샷은 건드리지 않는다.
- 메모리 압박은 `vm_stat`, `sysctl vm.swapusage`, 프로세스별 RSS로 본다. 정리는 agent-resource-hygiene.

## 비밀값과 에이전트 도구
- 평문 파일에 든 자격 증명은 키체인(`security` 명령)으로 옮기고, 스크립트는 실행할 때 키체인에서 읽는다. 값은 출력하지 않는다.
- 에이전트의 삭제 안전 검사가 변수가 든 경로(`rm -rf $TMPDIR/...`)를 막을 수 있다. 확인한 실제 경로를 그대로 쓴다.
