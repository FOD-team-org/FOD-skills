# 오디오·음성 합성 점검

소리는 최종 파일에서 숫자로 재고, 목소리 선택은 사람이 귀로 한다.

## 언제
- 렌더 직후, 게시 전
- "소리가 크다·작다", "음악 때문에 집중이 깨진다" 같은 지적을 받았을 때
- 음성 합성 엔진·목소리·말투 설정을 바꾸거나 고를 때

## 라우드니스 기준 (공개 기준, 프로젝트 문서에 하나를 고정)
| 용도 | 통합 라우드니스 | 트루 피크 |
|---|---|---|
| 스트리밍 영상 플랫폼 관행 | -14 LUFS | -1 dBTP 이하 |
| 팟캐스트·음성 위주 | -16 LUFS | -1 dBTP 이하 |
| 방송(EBU R128) | -23 LUFS | -1 dBTP 이하 |

- 효과음·타격음이 많은 포맷은 통합값이 맞아도 크게 들린다. 순간 최대(M)·단기 최대(S) 상한을 따로 정해 함께 잰다.

## 측정
1. 최종 인코딩된 파일로 잰다. 인코딩 전 wav로 잰 값은 인코딩 뒤 피크와 다르다.
2. 통합·범위·트루 피크:
   `ffmpeg -hide_banner -nostats -i final.mp4 -af ebur128=peak=true -f null -`
3. 순간·단기 최대: 같은 명령에 `framelog=verbose`를 더하고 출력의 `M:`, `S:` 값 중 최대를 코드로 뽑는다.
4. 꼬리 무음:
   `ffmpeg -hide_banner -i final.mp4 -af silencedetect=noise=-50dB:d=0.3 -f null -`
   마지막 `silence_start`와 전체 길이의 차이를 꼬리 무음으로 기록한다. 상한은 프로젝트 기준에 적는다.
5. 배경음악이 음성 대역과 겹치는지, 효과음 개수가 과한지 듣고 기록한다. 비트가 강한 음악은 정보 전달을 방해한다.
6. 측정값을 QA 기록 파일에 남긴다.

## 주음성 언어
- 주 시청층이 듣는 언어로 주음성을 만든다. 오디오만 듣는 사람이 있다.
- 외국어 원음에 번역 자막만 다는 구성은 쓰지 않는다.
- 원음을 깔 때는 주음성보다 충분히 낮춘다. 같은 언어 두 목소리를 같은 크기로 겹치지 않는다.
- 원음을 주음성으로 두는 것은 발화 자체가 소재일 때만 예외로 하고, 사유를 기록한다.

## 엔진 전환·폴백
- 엔진은 설정 스위치 하나로 고른다. 이전 엔진 경로는 폴백으로 남긴다.
- 키는 저장소 밖이나 커밋하지 않는 설정 파일에 둔다.
- 크레딧 소진·결제 필요 응답이 오면 폴백으로 결과물을 쌓지 말고 먼저 사람에게 충전 여부를 묻는다. 목소리가 다른 폴백본은 결국 쓰지 못한다.
- 폴백으로 만든 결과물은 기록에 폴백 사실을 적는다.

## 합성 캐시 일관성
- 캐시 키는 원문 텍스트 해시와 목소리·설정으로 정한다.
- 사전 합성을 따로 하지 않는다. 빌더를 먼저 한 번 돌려 캐시와 문장별 길이를 얻고, 그 길이로 다른 작업을 맞춘다.
- 테스트 빌드를 새 폴더에서 돌릴 때는 기존 캐시를 먼저 복사한다. 본 빌드와 시험 빌드의 작업 폴더를 같게 둔다.
- 재합성 건수를 보고한다. 0이어야 할 때 1건이라도 나오면 멈춘다.
- 음성 길이는 빌더와 같은 도구·버전으로 잰다. 도구 버전이 다르면 길이가 달라진다.
- 고칠 때는 바뀐 문장만 다시 합성한다. 전체를 다시 합성하면 템포가 달라진다.

## 목소리·말투 샘플 비교
1. 같은 문단으로 조건 하나씩만 바꾼 샘플을 만든다(문장안 × 설정 × 목소리 표).
2. 속도(초당 음절)와 음량을 맞춘다. 맞추지 못한 차이는 표에 밝힌다.
3. 숫자는 말로 풀어 쓴 문장으로 보낸다.
4. 판정은 사람이 듣고 한다. 에이전트는 소리의 좋고 나쁨을 판정하지 않는다.
5. 크레딧 사용량을 기록한다. 고른 목소리·속도·감정 설정은 프로젝트 설정에 고정한다.
6. 길이 예측은 고른 목소리의 실측 음절 속도로 한다.

## 확인
- 측정값이 최종 파일 기준이고 프로젝트 기준 안이다.
- 재합성 건수와 크레딧 사용량이 보고에 있다.
- 음성 인식으로 역전사해 대본과 대조했다. 인식 오류로 보이는 차이는 사람이 들어서 확인한다.

## 하지 않는 것
- 통합 라우드니스 하나만 보고 통과시키지 않는다.
- 합성 비용을 아끼려고 샘플 수나 검수 범위를 줄이지 않는다.
