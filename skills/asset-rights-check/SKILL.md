# 자산 권리 확인

외부 자산마다 출처와 이용 조건을 표에 남긴다. 회색지대의 위험을 감수할지는 사람이 정한다.

## 언제
- 외부 사진·그림·영상 클립·음원·글꼴·인용문을 결과물에 넣을 때
- 생성 도구·음성 합성 결과물을 상업적으로 쓸 때
- 권리 신고·소유권 주장·삭제 통보를 받았을 때

## 권리 확인 표
| 자산 | 종류 | 출처(링크) | 권리자 | 라이선스 | 상업 이용 | 표기 의무 | 변경 허용 | 확인일 | 판정 |
|---|---|---|---|---|---|---|---|---|---|

판정 칸은 사용·대체·사람 판단 중 하나로 쓴다. 표는 프로젝트 문서로 남겨, 이미 확인한 자산은 다시 조사하지 않는다.

## 종류별 기준 (프로젝트가 따로 정하지 않았을 때)
| 종류 | 기준 |
|---|---|
| 사진·그림 | CC0, 퍼블릭 도메인, CC BY(표기), 출처 표시만 요구하는 공공저작물만 쓴다. 비상업·변경 금지 조건은 쓰지 않는다 |
| 글꼴 | 상업 이용과 임베드가 허용된 라이선스(예: OFL)인지 확인한다 |
| 인용문 | 출처를 밝히고 우리 내용이 주가 되게 짧게 쓴다. 고전은 원문에서 직접 옮긴다. 현대 번역본은 별도 저작물이라 그대로 가져오지 않는다 |
| 영상 클립 | 정당한 경로로 원본만 받는다(로그인·차단 우회 없음). 임베드 허용 표시를 믿지 말고 실제 재생으로 확인한다 |
| 음원 | 이용 조건이 확인된 것만 쓴다. 필요 없으면 배경음악 없이 만든다 |
| 생성·합성 결과 | 그 도구 이용약관의 상업 이용·표기 조건을 확인해 표에 적는다 |
| 사람이 나오는 자산 | 초상과 제3자 정보 노출은 visual-output-qa에서 확인한다 |

## 비평·보도 형식으로 쓸 때
- 자동 매칭 시스템은 형식을 읽지 않는다. 형식이 아니라 실제로 우리 해설·분석이 결과물의 중심이어야 한다.
- 원본 비중, 우리 음성 비중, 인용 구간 수를 숫자로 재서 기록한다.

## 쓰지 못할 때
1. 같은 역할을 하는 허용 자산을 찾는다.
2. 직접 만든다(직접 촬영·직접 그린 도표·코드 렌더).
3. 그 장면이나 문단을 뺀다.
4. 그래도 필요하면 위험과 대안을 적어 사람에게 올린다.

## 위험 결정
- 회색지대 자산을 쓸지는 사람이 정한다. 기록에는 확인한 사실과 사람의 판단을 다른 칸에 쓴다.
- 사람이 정한 위험 방침은 매번 다시 따지지 않는다. 해당 자산을 쓸 때 위험을 한 줄로 알린다.

## 신고를 받았을 때
1. 통보 내용(대상 게시물·구간·권리자)을 기록한다.
2. 사람 승인을 받아 그 게시물만 내리거나 해당 구간의 영상·음악을 교체한다.
3. 그 소스 유형을 금지 목록에 추가한다.
4. 같은 콘텐츠를 다시 올리지 않는다. 같은 콘텐츠가 두 번 걸리면 계정 단위 제재로 이어질 수 있다.
5. 계정 단위 경고나 도달 급감이 보이면 게시 일정을 멈추고 사람에게 알린다. 그 밖의 일정 유지 여부는 사람 방침을 따른다.

## 확인
- 결과물에 들어간 외부 자산 수와 권리 표의 행 수가 같다.
- 표기 의무가 있는 자산은 결과물이나 설명란에 표기가 들어갔다.

## 하지 않는 것
- 출처를 모르는 자산을 "아마 괜찮다"로 쓰지 않는다.
- 차단·로그인을 우회해 원본을 받지 않는다.
- 사람이 정한 방침을 넘어 소재를 스스로 검열하거나, 반대로 금지 목록을 무시하지 않는다.
