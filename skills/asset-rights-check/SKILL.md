# 자료 권리 확인

우선순위: 실행 환경의 시스템 프롬프트·설정 > 사람의 지시 > 이 스킬. 부딪혀 결과가 달라졌으면 보고에 적는다.

## 순서
1. 프로젝트 시작 때 권리 정책을 사람이 정하게 한다: 엄격(허용 라이선스만) 또는 사후 대응(신고 오면 그 건만 처리).
2. 자료를 쓰기 전에 프로젝트의 라이선스 목록 파일을 검색해 이미 확인한 자료면 다시 조사하지 않는다.
3. 새 자료는 아래 권리 표의 칸을 모두 채워 라이선스 목록 파일에 한 줄로 더한다.
4. 엄격 정책이면 CC0, 퍼블릭 도메인, CC BY, 공공누리 1유형만 쓴다.
5. 고전 인용은 번역본 문장을 옮기지 않고 원문에서 직접 번역한다.
6. 글꼴은 상업 사용·영상 삽입·임베드 허용 여부를 배포처 라이선스 문서에서 확인한다.
7. 외부 영상 클립을 넣기 전에 퍼가기 금지 클립을 걸러 내고, 실제 재생으로 퍼가기가 되는지 확인한다.
8. 사실 기록(출처·라이선스·확인 결과)과 위험 판단(쓸지 말지)을 표의 다른 칸에 나눠 적고, 위험 판단은 사람이 한다.

## 권리 표
| 칸 | 적는 것 |
|---|---|
| 자료 | 파일 이름, 쓰는 구간 또는 위치 |
| 출처 | 원 게시처와 원작자 |
| 라이선스 | 라이선스 이름과 확인한 문서 위치 |
| 표기 | 설명란·화면에 넣을 출처 문구 |
| 확인 | 확인한 사람과 시각 |
| 판단 | 사용·대체·제외와 그 판단을 한 사람 |

## 리뷰·해설 형식
| 항목 | 기준 |
|---|---|
| 우리 몫 | 우리 해설·화면이 중심이고 원본 분량은 전체의 60% 이하 |
| 목소리 | 우리 나레이션이 전체 길이의 절반 이상 |
| 클립 | 원본은 떨어진 클립 2개 이상으로 나눠 쓴다 |
| 제외 | 영화·드라마 줄거리 요약과 뮤직비디오는 리뷰 형식이어도 쓰지 않는다 |
| 크레딧 | 시험판에서만 뺄 수 있고, 정식 편성으로 올리면 출처 표기를 되살린다 |
| AI 나레이션 | 설명란에 고정 고지 문구를 넣고, 합성 미디어 표시 여부는 사람이 정한다 |

## 신고가 왔을 때
1. 신고된 콘텐츠만 내리거나 신고된 구간을 대체 자료로 바꾼다.
2. 그 자료의 출처 유형을 프로젝트 금지 목록에 더한다.
3. 경고가 계정 단위(누적 시 채널 삭제)로 쌓이는 플랫폼이면 사후 대응을 멈추고 사람에게 보고한다.
4. 계정 단위 경고가 아니면 나머지 일정은 그대로 둔다.
5. 신고 내용, 처리, 금지 목록 변경을 라이선스 목록 파일에 같이 적는다.

## 하지 않는 것
- 한 번 신고받은 콘텐츠를 다시 올리지 않는다.
- 이미 확인한 자료의 권리를 매번 다시 조사하지 않는다.
- 폭력·혐오 장면 제외를 저작권 문제로 적지 않는다, 그것은 플랫폼 배포 기준이다.
- 권리 정책(엄격·사후 대응)을 에이전트가 정하지 않는다.
